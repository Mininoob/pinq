# Surface brief: Pinq website (site/index.html)

Scope: the public open-source launch page for Pinq, deployed on Vercel from `site/`. Mode: **Persuade**.

Audience & job: everyday desktop note-keepers first (see it work, download); local-first/PKM fans and contributors second (trust, source, license). Action: Download (GitHub Releases, Windows + macOS). Proof: the product demonstrated by a note doing each thing; no testimonials, counts, or awards exist. Constraints: MIT; macOS build unsigned (say so); reduced-motion and no-JS must get the full content.

Memorable moment: the top sticky rips off the pad and travels down the page, becoming every feature in turn.

## Direction contract

THESIS: The page is a pad you pull from. One sticky tears off the hero pad and travels the whole page, demonstrating each capability by doing it. Refuses the category default of a centered headline over an app screenshot and a three-card feature grid.

OWN-WORLD: Warm stone ground (#ECEAE6 family, never cream) with ink #242322 text; the sticky is the only colour field — yellow #FFD45C paper, coral #FF6F6C peel — so colour always means "a note". Geist Black display, tight negative tracking, at poster scale; Geist body. Floating pill nav, black pill CTAs, pill chips. Stationery spec-callout labels (mono-free: Geist small caps with hairline rules) number the chapters. One atmospheric wallpaper photograph is the hero desktop. Every note pose and chip locks to a square module.

STORY: A visitor sees a desktop with a pad, watches a note rip off, then sees that same note type without wrapping, become a checklist, take a dropped file, link to other notes, get thrown into an edge tab, and appear on a second device. They understand Pinq is tactile stickies with a real library underneath, that it is local-first, encrypted, free and MIT-licensed, and they download it.

FIRST VIEWPORT: Pill nav top-centre (mascot+Pinq, Features, Open source, GitHub, black pill Download). Left/centre: no kicker; a two-line Geist Black headline at ~clamp(48px, 7vw, 104px), one sentence, black pill Download plus quiet "View on GitHub", platform chips. Right/lower: a rounded desktop frame showing the wallpaper photo with the Pinq pad docked on its right edge and the top sticky (smiley, coral corner lifting) resting on a visible stack of sheets.

FORM: Pinned user concept "The Pad You Pull From", position 1 of the grounded list (the sticky pad itself); roll assigned index 5 (stationery packaging) translated into the chapter spec-callout labels and the colour swatch fan. Raises: square-module lock (Studio Dumbar), accumulating note record (coiled tower), paper translucency + inner light (Akari), deep-linkable 01–06 legend (jackfield), closing six-note constellation (six-pack). Seed key cab3c868.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Signature interaction (code-led): one sticky stage pinned while chapters scroll; scroll-scrubbed GSAP timeline drives the corner curl, torn-edge rip, detach overshoot, and per-chapter morphs; soft snap to each chapter's complete state; reduced-motion shows each pose statically in place.
